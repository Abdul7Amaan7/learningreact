# React Interview Guide

A local study site covering React fundamentals through Next.js: in-depth explanations, pitfalls, and interview Q&A.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (usually http://localhost:5173).

- Search: `Ctrl+K` / `Cmd+K`
- Mark topics done (saved in `localStorage`)
- Sidebar lists all 19 chapters

## Stack

Vite, React 19, React Router, TypeScript. Content lives in `src/content/chapters/`.
